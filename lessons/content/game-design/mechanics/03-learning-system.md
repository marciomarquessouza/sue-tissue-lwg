### 3.1 Pedagogical Progression

O Learning System controla exclusivamente a progressão educacional.

O conteúdo é organizado em níveis e módulos, como A1.1, A1.2 e A2.1.

**Regras:**

* O jogador pode selecionar livremente qualquer nível disponível.
* Não é necessário concluir níveis anteriores.
* Dentro de um módulo, as lições seguem uma sequência obrigatória.
* Lições concluídas podem ser repetidas integralmente.
* O progresso educacional é preservado entre ciclos de morte.
* A progressão pedagógica não depende da conclusão de acontecimentos narrativos.

Inicialmente, os módulos são planejados com 30 lições, mas essa quantidade poderá ser ajustada.

### 3.2 Little Ghosts (LGs)

Os Little Ghosts são criaturas utilizadas para representar unidades de conhecimento.

Cada LG corresponde a uma entrada de aprendizagem, que pode representar uma palavra, expressão ou conceito gramatical.

Uma entrada gramatical pode conter múltiplos exemplos dentro do mesmo LG.

O número de LGs depende do conteúdo de cada lição, com um máximo recomendado de oito.

### 3.3 Learning Activities

As atividades são conduzidas por Eliza durante os sonhos de Josef.

Cada LG pode apresentar até quatro etapas:

**Introduction**

Apresentação breve e objetiva do conteúdo, com explicações práticas.

**Listening**

Reprodução de áudio para que o jogador escute a palavra ou expressão.

**Pronunciation**

O jogador utiliza o microfone para pronunciar o conteúdo.

Uma API avalia a gravação e retorna uma pontuação. Josef apresenta animações associadas à fala captada.

**Writing**

O jogador completa palavras ou frases utilizando um quadro de letras.

Uma ou mais etapas podem ser omitidas conforme a natureza do conteúdo.

### 3.4 LG Performance

O desempenho nas atividades de Pronunciation e Writing determina o resultado de aprendizagem do LG.

Um desempenho insuficiente pode fazer com que ele adquira uma aparência Evil.

O jogador pode revisar voluntariamente os LGs durante a lição.

Após o aprendizado, os Little Ghosts acompanham Josef até o Guardião da Memória.
